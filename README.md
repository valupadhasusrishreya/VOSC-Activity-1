\# Tic-Tac-Toe Game



\## About the Project



This is a simple two-player Tic-Tac-Toe game created as part of VOSC Activity 1.



The game is built using:



\- HTML

\- CSS

\- JavaScript



\## Features



\- Two-player gameplay

\- Player X and Player O take turns

\- Automatic winner detection

\- Draw detection

\- Restart game button

\- Simple and user-friendly interface



\## How to Play



1\. Open the `index.html` file in a web browser.

2\. Player X starts the game.

3\. Click on an empty cell to place your symbol.

4\. Players take turns between X and O.

5\. The player who gets three symbols in a row wins.

6\. If all cells are filled without a winner, the game ends in a draw.

7\. Click the \*\*Restart Game\*\* button to play again.
